## Tanmay Bhamare – Netflix Inspired Portfolio

This is my personal portfolio website built with a Netflix-style UI. It showcases my projects, skills, and experience in web development while keeping the interface clean and modern.

---

## Tech Stack

* React
* Tailwind CSS
* DatoCMS (Headless CMS)
* AWS S3 & CloudFront
* GitHub Actions

---

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd <repository-folder>
```

### 2. Use Node 18

```bash
nvm install 18
nvm use 18
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the project

```bash
npm start
```

Then open the local server URL in your browser.
